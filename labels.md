# Label standar (buat di setiap repo)

| Label | Warna | Kegunaan |
|---|---|---|
| `tugas` | `#1F4E79` | Pekerjaan konkret |
| `data` | `#2E8B57` | Terkait dataset/katalog data |
| `teknologi` | `#6A5ACD` | Platform, kode, integrasi |
| `implementasi` | `#E8731A` | Pekerjaan di lapangan/mitra |
| `dokumentasi` | `#0E8A9E` | README, playbook, notulen |
| `masalah` | `#D73A4A` | Ada yang salah |
| `butuh-bantuan` | `#FBCA04` | Mencari kontributor |
| `good-first-issue` | `#7057FF` | Cocok untuk anggota baru |
| `diskusi-rutin` | `#C5DEF5` | Bahan/tindak lanjut sesi diskusi rutin |
| `keputusan` | `#000000` | Butuh atau berisi keputusan pengurus |

Tip: label bisa disalin antar-repo dengan GitHub CLI:
`gh label clone idtc-id/pokja2-handbook --repo idtc-id/<repo-tujuan>`
